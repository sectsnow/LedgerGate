# 后台界面巡检（2026-11-22）

本轮检查覆盖整个后台的布局与页面交互，按个人自用、单实例部署验证。

已修复的问题：

1. 网关密钥页在窄屏中将“访问凭据”“复制地址”挤成竖排，360px 时复制按钮被裁切。标题与地址允许换行，复制按钮保持完整，密钥表格保留可读列宽并支持横向滚动。
2. 连续长字符组成的账户名会撑开账户卡片，导致首页、账户列表出现横向溢出。名称区域允许收缩，标题按可用宽度换行。
3. 长账户名、模型名或弹窗标题会挤走关闭按钮，并让弹窗正文出现横向滚动。公共标题允许换行，弹窗关闭按钮保留宽度和间距。

本轮修改复用现有组件与公共样式，仅调整 `web/src/main.tsx` 和 `web/src/style.css`，未新增依赖。
