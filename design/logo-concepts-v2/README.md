# LedgerGate Logo 概念

第二组：十种不同风格的矢量方案，编号 11—20，供选择。

| 编号 | 名称 | 图形构思 |
| --- | --- | --- |
| 11 | 手写签名 | 自由笔画 · 有个人作品的温度 |
| 12 | 中式方印 | 门与账的篆刻构图 · 温润朱砂红 |
| 13 | 像素终端 | 8-bit 字母块 · 复古开发者气质 |
| 14 | 极简线框 | 细线 LG 与接口括号 · 轻巧克制 |
| 15 | 网关徽章 | 盾形章徽 · 稳定、守护与秩序 |
| 16 | 柔和花瓣 | 有机曲线汇聚 · 轻盈、亲和 |
| 17 | 复古票据 | 票据缺口与 LG 暗记 · 老派账房感 |
| 18 | 立体纸片 | 等距视角与柔和渐变 · 桌面应用感 |
| 19 | 账房猫 | 吉祥物路线 · 轻松、有记忆点 |
| 20 | 纯字标 | 定制字母结构 · 品牌名直接成为标志 |

overview-light.png / overview-dark.png：编号对比总览。

options/：各款独立图标，提供浅色配色、深色配色、单色与反白 SVG，以及透明 PNG。

SVG 为自行编写的图形路径；PNG 由同一套图形渲染。此目录用于设计选择，应用界面尚未接入。

20 为纯字标方案，wordmark-*.svg 是完整品牌字标；light.svg / dark.svg 是小尺寸 LG 备用标。完整字标的字母由独立路径构成，不依赖字体。
