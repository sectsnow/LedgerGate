# LedgerGate Logo 概念

十款独立设计的矢量概念。当前应用选用 03「汇流」。

| 编号 | 名称 | 图形构思 |
| --- | --- | --- |
| 01 | 门账 | 门形入口 × 账本刻度 |
| 02 | 交织 LG | L 与 G 咬合，简洁的字母标记 |
| 03 | 汇流 | 多路上游，汇入同一出口 |
| 04 | 折页门 | 账本折页中留出一道门 |
| 05 | 账环 | 环形 G 与三道账目刻度 |
| 06 | 协议棱镜 | 多面接口，统一连接 |
| 07 | 双页桥 | 展开的账本，也是连接两端的桥 |
| 08 | 运维哨塔 | 监控信号与稳定守望 |
| 09 | 回环 | 连续流转与自动故障切换 |
| 10 | 层账 | 账户、账目与请求逐层归集 |

overview-light.png / overview-dark.png：编号对比总览。

options/：各款独立图标，提供浅色配色、深色配色、单色与反白 SVG，以及透明 PNG。

SVG 为自行编写的图形路径；PNG 由同一套图形渲染。03「汇流」的应用版本位于 `web/public/ledgergate-logo.svg`。
